Typography

Two faces with a strict division of labour: Spectral is reserved for Dutch — every word specimen, every example sentence, every screen title — and Hanken Grotesk carries all UI chrome. The split is the point: a learner can tell at a glance which text is the language they're learning and which is the app talking. Sizes come from Figma as --size-* tokens; the families are hand-authored so fallback stacks survive.

Rules worth keeping

Serif means Dutch. If a string is Dutch the learner is meant to read, it is Spectral. If it is the app speaking — a button, a label, a hint — it is Hanken Grotesk. The one deliberate exception is the wordmark, which is serif because it is a name, not chrome.

Examples are italic. Every in-context sentence is Spectral italic at 16/1.5 — that is what separates "a sentence using this word" from "the app's own copy about the word".

Labels are the only uppercase. Tracking is doing the work at 12px; nothing larger is ever set in caps.
